# LENDINGOPS SUITE 3.0

LendingOps Suite is a business reporting and operations application designed to simplify report extraction, validation, market reporting, and operational data management.

## Features

- Business report extraction
- Report validation
- Historical report validation
- Market-based reporting
- Customer and ledger integration
- Automated calculations
- Structured business data processing

## Technology

- HTML
- CSS
- JavaScript
- Google Apps Script
- Google Sheets

## Project Status

Active development.

## Security

Sensitive credentials and API keys are not included in this repository.
